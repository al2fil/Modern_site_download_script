📖 Умный скачиватель сайтов (Tilda Parser)
Описание и инструкция по запуску для начинающих

🤖 Что умеет этот скрипт?
Это не просто «сохранить страницу как». Это умный робот, который открывает сайт в невидимом браузере, прокручивает его, скачивает все картинки, шрифты и стили, а затем аккуратно упаковывает всё для чтения без интернета.
Его суперспособности:
1.	Обходит хитрости Tilda: Сайты на Tilda подгружают картинки лениво (только когда вы до них доскроллили) и прячут их в фоны. Скрипт сам прокручивает страницы и «вытаскивает» все изображения.
2.	Чинит кликабельные карточки: В оригинале клик по картинке рецепта работает за счет JavaScript. Офлайн JS не работает, поэтому скрипт сам «оборачивает» картинки в ссылки, чтобы вы могли кликать по ним мышкой.
3.	Блокирует мусор: Скрипт встроенным фаерволом отключает загрузку Яндекс.Метрики, VK и прочей аналитики. Благодаря этому сайт скачивается в 5 раз быстрее.
4.	Создает красивый Лаунчер: После скачивания в папке появляется красивая стартовая страница с таймером обратного отсчета, которая сама откроет нужный раздел.
5.	Многопоточность: Робот открывает сразу 5 вкладок одновременно, экономя ваше время.

🛠 Шаг 0. Подготовка (Установка Python)
Для работы скрипта на компьютере должен быть установлен язык программирования Python (версия 3.8 или новее).

•	Для Windows:
1.	Зайдите на официальный сайт python.org/downloads.
2.	Скачайте и запустите установщик.
3.	⚠️ САМОЕ ВАЖНОЕ: В самом первом окне установки обязательно поставьте галочку Add Python to PATH (Добавить Python в путь).
4.	Нажмите Install Now.

•	Для Linux (Ubuntu/Debian/Mint): Python обычно уже установлен. Откройте терминал и убедитесь, что есть менеджер пакетов pip: 
sudo apt update && sudo apt install python3 python3-pip -y

🪟 Инструкция для Windows
1. Подготовка папки
1.	Создайте на Рабочем столе новую папку, назовите её, например, Скачиватель.
2.	Скопируйте код скрипта, создайте внутри этой папки текстовый документ и назовите его download_tilda.py (обязательно удалите .txt!).
2. Запуск командной строки
1.	Нажмите на клавиатуре Win + R, введите cmd и нажмите Enter. Откроется черное окно.
2.	Лайфхак для чайников: Чтобы не писать путь к папке вручную, введите в черном окне команду cd (обязательно с пробелом после cd).
3.	Затем просто перетащите мышкой вашу папку Скачиватель с рабочего стола прямо в черное окно и нажмите Enter. Путь подставится сам!
3. Установка библиотек и браузера
Введите по очереди следующие две команды (или запусти install.cmd):
pip install playwright beautifulsoup4
python -m playwright install chromium
(Вторая команда скачает "движок" браузера Chromium весом около 150 МБ. Антивирус может на секунду ругнуться — это нормально, разрешите).
4. Запуск скачивания
Находясь всё в том же черном окне, введите (или запусти download.cmd):
python download_tilda.py
Смотрите, как в папке начинают появляться файлы и папки! 🚀

🐧 Инструкция для Linux (Ubuntu / Mint / Debian)
1. Подготовка
1.	Создайте папку и сохраните в неё скрипт download_tilda.py.
2.	Откройте Терминал (Ctrl + Alt + T).
3.	Перейдите в папку со скриптом (например: cd ~/Загрузки/Скачиватель).
2. Установка зависимостей
2.1 В Linux Playwright требует системных библиотек для рендеринга шрифтов и картинок. Введите эти команды:
pip3 install playwright beautifulsoup4
python3 -m playwright install chromium
2.2 Эта команда установит скрытые системные библиотеки Linux, нужные браузеру:
python3 -m playwright install-deps chromium 
3. Запуск
Запустите скрипт командой:
python3 download_tilda.py

🎉 Как пользоваться скачанным сайтом?
1.	После того как скрипт закончит работу (в консоли появится надпись 🎉 Готово!), зайдите в появившуюся папку. Она будет называться по имени сайта (например, your.site).
2.	Найдите в корне этой папки файл, который начинается с восклицательного знака, например: !Запуск_your.site_page1.html.
3.	Дважды кликните по нему.
4.	Откроется ваш обычный браузер с красивой заставкой. Таймер отсчитает 5 секунд, и вы автоматически попадете в раздел рецептов.
5.	Теперь интернет можно отключать! Картинки, переходы между рецептами и стили будут работать идеально.

________________________________________
⚠️ Важные нюансы (Почему что-то может не работать)

•	Поиск по сайту и кнопки "Записаться": Они не будут работать. Поиск требует подключения к базе данных на сервере клиники, а формы записи отправляют письма на их почту. В офлайн-режиме работают только чтение и навигация.

•	Структура папок: Внутри папки your.site лежит папка assets (там хранятся все картинки и стили). Никогда не удаляйте и не переименовывайте её, иначе сайт "ослепнет" и останется без картинок.

•	Антивирусы (Kaspersky, ESET): Иногда они блокируют playwright, так как он скачивает браузер в скрытом режиме. Если установка зависает или выдает ошибку доступа — временно приостановите защиту антивируса на 2 минуты, пока скачивается Chromium.

•	Ошибки "Timeout": Если интернет медленный, некоторые "тяжелые" страницы могут не успеть загрузиться за 45 секунд. Скрипт умный и сделает 3 попытки, но если страница всё равно пропустится — просто запустите скрипт еще раз, он докачает пропущенное (благодаря умной системе очередей).
